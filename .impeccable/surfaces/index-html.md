# 首页

- Scope: `index.html` mobile PWA surface
- Mode: Operate
- Audience: 中文手机用户在私人环境中完成每日记录
- Primary task: 三秒内选择“没冲”或“冲了”
- Secondary tasks: 查看趋势、恢复估算、排行榜、提醒和历史
- Truth: 详细历史默认只在本机；公开榜只同步用户主动公开的 ID 与连续数据
- Constraints: 保留现有存储键、模块协议、PWA、排行榜与 120 小时恢复估算
- Direction: Quiet Continuum。冷银灰连续空间、近黑排版、唯一 Apple Blue、局部 Liquid Glass 近似材质
- Memorable moment: 双选活动层完成材质迁移，选择立即成为连续记录的一部分
- Motion: GSAP Opening Resolve、Choice Morph、Continuity Reveal、Depth Scroll、Sheet Lift
- Risk: 低信息密度不能隐藏进阶功能；二级抽屉必须与首屏拥有同一视觉语法
